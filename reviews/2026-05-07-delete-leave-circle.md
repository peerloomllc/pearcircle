# REVIEW — delete-circle (owner) and leave-circle (member)

**Date**: 2026-05-07
**Tier**: T3
**Proposal**: `proposals/2026-05-07-delete-leave-circle.md`
**Decision**: `DECISIONS.md` 2026-05-07 — circle delete (owner) + circle leave (member); proposal approved

Wire-protocol v1 amended additively. The existing `circle:` row now carries optional `deleted: boolean, deletedAt: number` fields (mirrors the `place:` soft-delete pattern from DECISIONS 2026-05-05); the apply branch is unchanged for the storage path (still owner-write only, still no LWW since the owner is the sole writer of `circle:`) but now emits a `circle:deleted` worklet event when a tombstone lands, suppressed on the writer's own device so owners don't get notified about their own delete. A new `left:{pubkey}` keyspace is signed by the leaver and verified self-write only (mirrors the `lastSeen:` and `transition:` rules). Snapshot helpers (`snapshotCircle`) filter the leaver's `member:`/`lastSeen:`/`presence:` rows via the rule "hide if `left.leftAt > member.joinedAt`", which means rejoin is a fresh `member:` write whose `joinedAt` is newer — no explicit unset needed. Filter helpers `circleIsDeleted` and `memberHiddenByLeft` extracted to `src/lib/circleFilter.js` with `tests/circleFilter.test.js` covering threshold, sentinel, and rejoin cases. Affects `src/bare.js` (new `circle:delete` / `circle:leave` / `circle:rename` / `circle:cleanup-deleted` IPCs, `tearDownCircleLocally` helper, init-time stale-deleted sweep that silently cleans up local state when an owner's tombstone landed in a previous session but the `circle:deleted` UI event was lost — patched separately on field-test discovery), `app/index.tsx` (forwards `circle:deleted` event), and `src/ui/App.jsx` (Circles section in Settings with two-tap delete/leave confirms + inline rename for owners; `CircleDeletedNotice` modal for peer-side; defensive filter on `HomeMapView.refresh` so the dropdown / pill / roster all match Settings; refresh-on-open + 5s poll while active so peer-side renames sync into Settings). Manual cross-device smoke on 2026-05-07: D1 deleted a circle, D2 received the modal and OK'd it, circle vanished everywhere; D1 created and renamed a circle, D2 saw the rename in both pill and Settings within seconds; stale-deleted sweep verified by leaving D2 in a state where it had a deleted-tombstone autobase but no local cleanup, then cold-starting — the stale entry disappeared without a fresh notice. Records pile up in the underlying Autobase log; defer to the future retention sweep slice. v1 remains the floor — no peers have shipped beyond the two test devices. `npm run verify`: 114 tests / 10 suites green; both bundles build clean. Signed off by Tim.
